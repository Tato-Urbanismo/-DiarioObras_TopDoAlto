📷 Importar Fotos da Planilha

Selecione a pasta xl\media (com todas as fotos originais da planilha). O sistema identifica a data de cada foto automaticamente e anexa ao diário correspondente — as fotos já importadas não são duplicadas, então pode rodar de novo quantas vezes precisar.

☁ Enviar Diários para o Google Drive

Envia os PDFs dos diários dentro do período escolhido para o Google Drive, um de cada vez. Use para enviar apenas os diários que já estão prontos, sem mexer nos demais.
